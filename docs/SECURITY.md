# Security

## Secrets

- `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` read from env only.
- `.env` is gitignored; never commit.
- Never log raw API keys; redact in adapter error messages.

## Prompt handling

- User prompts may contain PII. Adapter logs only prompt hash + length unless `--debug-unsafe` is set.
- LLM responses cached on disk under `~/.cache/terpix/`; cache key is hash of (prompt, model, params). User can wipe with `terpix cache clear`.

## Subprocess

- ffmpeg invoked with arg array (never shell string) — no command injection.
- Input video path validated (`fs.statSync`) before passing to ffmpeg.
- Output paths: refuse to write outside cwd unless `--out-anywhere` is set.

## Terminal injection

- LLM output is JSON-parsed before any byte reaches stdout. Free-form text from LLM is **never** written directly to terminal — terminal output is generated by encoder from RGB frames only.

## Threat model

- Trusted local user. Not designed for multi-tenant servers. SSH usage is fine (no privilege escalation).
